# .vsix ファイルの作成方法

## 背景
VS Code 拡張機能をパッケージ化して `.vsix` ファイルを作成する方法についての備忘録。

## 手順

1. **ツールの確認**
   - `@vscode/vsce` が必要。このプロジェクトでは `devDependencies` に含まれている。

2. **パッケージ化コマンドの実行**
   - `package.json` に `package` スクリプトが定義されている。
   - 以下のコマンドを実行する：
     ```bash
     pnpm package
     ```
   - または直接 `vsce` を使う場合（`pnpm exec` 経由）：
     ```bash
     pnpm exec vsce package
     ```

3. **出力の確認**
   - 成功すると、ルートディレクトリに `{name}-{version}.vsix` ファイルが生成される。

## 注意事項
- `publisher` が `package.json` に設定されている必要がある。
- 初回実行時や Marketplace へのアップロード時には認証を求められることがあるが、ローカルでのパッケージ化のみならスキップ可能な場合が多い。
- このプロジェクトでは既に `package` スクリプトがあるから、それを使うのが一番楽。
