# デバッグ情報の出力先と有効化方法について

この拡張機能（No-Send-Enter）では、開発やトラブルシューティングのために詳細な実行ログを出力する機能が備わっています。

## デバッグ情報の出力場所

VS Code および Antigravity の **Output（出力）** パネルに出力されます。

1.  VS Code の下部にあるパネルを開きます（`Ctrl+J` または `Cmd+J`）。
2.  **Output（出力）** タブを選択します。
3.  パネル右上のドロップダウンリストから **"No-Send-Enter"** を選択します。
    *   拡張機能がアクションを実行するたびに、ここにタイムスタンプ付きのログが表示されます。

## デバッグログの有効化方法

デフォルトではデバッグログは無効になっています。以下の手順で有効化できます。

1.  **Settings（設定）** を開きます（`Cmd+,` または `Ctrl+,`）。
2.  検索バーに `noSendEnter.debug` と入力します。
3.  **"No-Send-Enter: Debug"** という項目のチェックボックスをオンにします。

これで、Enter キーや Ctrl/Cmd+Enter キーを押した際のコマンド試行状況などが Output パパネルに記録されるようになります！
