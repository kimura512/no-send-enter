# Cursor Compatibility Update Walkthrough

## 背景
CursorのAIチャット入力欄において、`Enter`キーを押下した際に改行ではなくメッセージが送信されてしまう事象が発生していました。

## 実施した変更
`package.json` のキーバインディング (`noSendEnter.newline`, `noSendEnter.send`) に設定されている `when` 句に対して、Cursor 特有の入力欄フォーカスを表すコンテキストキーを追加しました。

具体的には、以下のコンテキストキーをOR条件で追加し、様々な Cursor の UI パターン（チャット欄、Composer機能など）で反応するように設定しています。

```json
(inChatInput || inlineChatFocused || aichatInputFocus || cursorChatInputFocus || aichat.input.focus || composerInputFocus || composer.isEditing || inComposer || editorPromptBarFocused || cursor.chat.active) && config.noSendEnter.enabled
```

## 検証とビルド
1. 上記の `when` 句の変更を `package.json` に適用。
2. `pnpm run package` を実行して、更新版の拡張機能 `.vsix` ファイル (`no-send-enter-0.1.0.vsix`) を正常にビルドしました。

最新のローカルの `.vsix` ファイルを Cursor にインストールすることで動作確認が可能です。
