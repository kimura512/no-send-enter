# Cursor 回避策 (マニュアル設定) の実装完了

## 背景
CursorのAIチャット入力欄は、VS Code標準のMonaco Editorではなく独立したWebコンポーネント(Lexical)で実装されているため、VS Codeの拡張機能（本プロジェクト `no-send-enter`）の `package.json` のキーバインディング設定からは `Enter` キーイベントを横取りできないことが判明しました。

## 実施した変更
拡張機能側で強引に制御することは不可能であるという設計上・技術上の結論に基づき、本リポジトリの `README.md` に **Cursorでの利用向け専用セクション** を追加しました。

Cursor ユーザーが自らの環境の `keybindings.json` に手動で追加することで、「Enter で改行、Cmd/Ctrl + Enter で送信」の振る舞いを完全に再現できる**決定版のJSONスニペット**を記載し、ドキュメントとしての解決を図りました。

```json
  {
    "key": "enter",
    "command": "type",
    "args": { "text": "\n" },
    "when": "composer.isEditing || aichat.input.focus || inComposer || cursorChatInputFocus"
  },
  // （以下略、README参照）
```
